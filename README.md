# SisKul - Sistem Ekstrakurikuler SMK Negeri 8 Malang

Aplikasi manajemen ekstrakurikuler dengan fitur:
- Data Siswa
- Jenis Ekskul
- Pembina
- Pendaftaran
- Absensi dengan Foto (Kamera)
- Rekapan Kehadiran Bulanan

## Akses Online
[https://siskul.vercel.app](https://siskul.vercel.app)

## Teknologi
- HTML5
- CSS3
- JavaScript
- LocalStorage
